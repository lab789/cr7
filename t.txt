Experiment 9 – Backup and Recovery
Aim

To perform database backup and recovery using MySQL.

Software Used
Ubuntu Linux
MySQL
Theory

Backup is the process of creating a copy of database data to prevent data loss. Recovery restores the database after accidental deletion or system failure. MySQL provides mysqldump utility for backup and restore operations.

Algorithm
Create database and table
Insert records
Take backup using mysqldump
Delete database
Restore database
Verify recovery
Important Commands Used
mysqldump collegeDB > collegeDB_backup.sql
DROP DATABASE collegeDB;
mysql collegeDB < collegeDB_backup.sql
Advantages
Prevents data loss
Easy recovery
Improves data safety
Result

Database backup and recovery were completed successfully.

Conclusion

Backup and recovery operations were successfully implemented using MySQL utilities.
